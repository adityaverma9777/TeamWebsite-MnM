Getting started with

Get a head start: Follow these steps to install Anitgravity, so you're ready to build the moment you walk through the doors.

antigravity.google
Step 01

Download & Install

  • Access the Platform: Navigate to antigravity.google and download the official installer.
  • Select OS Architecture: Download the appropriate build for your development environment (Windows, macOS, or Linux).
  • Execute Installation: Run the installer. The setup process is streamlined and built upon the familiar VS Code foundation.
Step 02

Initial Setup

Launch the application to initialize your environment configuration:

  • Authentication: Sign in using your Google account to access the preview build.
  • Environment Configuration: Seamlessly import your existing themes and keybindings from VS Code or Cursor, or initialize a fresh environment.
  • AI Policy Selection: Define the autonomy level for your AI assistant.
    Recommended: Agent-Assisted (The AI handles safe tasks autonomously but requires authorization before executing major changes).
Step 03

Workspace Architecture

Antigravity requires a dedicated, isolated workspace to execute operations.

  • Launch Mission Control: Access the Agent Manager from the central dashboard.
  • Initialize Environment: Select "+ Open Workspace" to create a dedicated context for the agent.
  • Directory Allocation: Create and select a new local directory. This serves as the secure environment where the agent will generate your project architecture.
Step 04

Prompt Deployment

Initiate development by communicating directly with the Agent Side Panel.

  • Activate Interface: Open the panel using the primary hotkey (Cmd + L or Ctrl + L).
  • Engage Planning Mode: Enable "Planning Mode" to instruct the AI to architect a comprehensive solution strategy before executing code.
  • Issue Directives: Provide explicit, functional specifications. (e.g., "Develop a responsive dashboard interface with dark-mode support using HTML and CSS").
  • Review & Validate: Monitor the agent's autonomous file generation. Use the built-in Browser Preview to instantly validate your build in real-time.
