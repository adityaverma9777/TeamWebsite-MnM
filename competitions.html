What is Morrow?

Morrow is an open-source hackathon organized by MnM (Makers Need More) where participants build solutions that continue to benefit people even after the event ends.

Every project is encouraged to remain open source so others can learn from it, contribute to it, and improve it.

Because the best software shouldn't disappear after judging.
